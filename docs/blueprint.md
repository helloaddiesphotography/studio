# **App Name**: Civics Whiz

## Core Features:

- Flashcard Generation: Generates flashcards with a question on one side and the answer on the other, based on the 100 civics questions.
- Intelligent Quiz: Uses an AI tool to dynamically tailor quizzes based on the user's performance. As the user answers, the system prioritizes questions from areas where the user shows less proficiency. 
- Progress Tracking: Keeps track of the user's progress, showing statistics and areas of improvement.
- Animated Interactions: Incorporate light, engaging animations for correct and incorrect answers.
- Personalized Study Plans: Generative AI is used to create study schedules based on individual timelines and learning preferences.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2), evokes trustworthiness and knowledge.
- Background color: Light grey (#F0F0F0), offers a clean and modern feel, avoiding distractions.
- Accent color: Energetic orange (#F2994A), used sparingly to highlight important information and call-to-action buttons.
- Body and headline font: 'Inter' for a modern, neutral, and easily readable sans-serif.
- Use simple, clear icons to represent different sections or types of questions.
- Clean and intuitive layout, emphasizing readability and ease of navigation.
- Smooth transitions and engaging animations to provide positive feedback and maintain user interest.
